# Versa Quick Game identity

Forest green, cream paddles, and a lime pickleball. The two paddles suggest a V and a friendly doubles game. Product copy: **No ratings. No fuss.** / **Good games. Great company.**

Created for this project using the built-in image-generation tool on September 23, 2026. The master PNG is preserved. Exports are plain RGB resizes for app/website use, not a vector logo. The 1024-pixel icon has a full square background; iOS applies the system icon mask.

Generation brief: A polished, minimal flat vector-style iOS app icon for “Versa Quick Game,” a friendly casual pickleball score-recording app. Full-bleed dark forest-green square, two cream pickleball paddles forming a loose V, one bright lime pickleball with clear circular holes centered above/between them. Simple strong silhouette, clean geometric shapes, generous spacing, no text, no letters, no gradients, no mockup or phone, no rendered rounded-square border. Consistent with the existing forest-green, off-white, lime interface theme.
